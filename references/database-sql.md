# 数据库与 SQL

## BLOCKER / MUST

- SQL 使用参数绑定，禁止把用户输入拼接到 SQL、排序片段或表名中；动态标识符必须白名单映射。
- 更新和删除必须有明确条件；批量操作要考虑事务、锁和分批，避免一次载入无法估算的大集合。
- 根据过滤、排序和连接条件设计索引，并用执行计划验证；不要仅凭字段数量猜索引是否有效。
- 分页、列表和导出明确上限；大偏移量场景评估游标/范围分页。

## SHOULD

- 业务表保留审计字段、唯一约束和删除策略，但具体字段以项目规范为准。
- 避免循环内逐条查询（N+1）；优先批量查询或合适的连接，注意结果集大小。
- 数据库迁移要可回滚或具备前向兼容步骤，先评估已有数据和在线变更影响。

ORM 语法以项目实际框架为准；MyBatis 的 `#{}`、JPA 参数绑定等是实现方式，不是跨框架的唯一写法。
