# /java-design

先确认需求边界并给出可执行方案；只有任务指向现有项目时才读取已有接口和技术栈。按问题选择最相关的 1～2 个主题，不要默认读取所有规则。只输出与方案有关的数据模型、接口契约、状态、失败路径和验证计划，不在方案阶段擅自修改代码。

复杂流程使用时序、状态或流程描述；数据库变更必须说明兼容、迁移和回滚策略。

共享规则入口：`../../SKILL.md`。
