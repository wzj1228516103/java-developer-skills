# /java-fix

先收集错误日志、复现步骤、变更范围和运行环境，区分事实、假设和待验证项。优先定位根因，再给出最小修复和回归测试；不要因为一个症状直接进行大规模重构。

涉及数据、权限、事务、缓存、消息或并发时，只读取实际相关的一个或两个规则，并说明修复后的关键副作用和验证结果。

共享规则入口：`../../SKILL.md`。
